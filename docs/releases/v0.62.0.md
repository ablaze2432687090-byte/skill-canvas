# Skill Canvas v0.62.0 — Public preview / 公开测试版

## 中文

首个公开 Windows x64 测试包：中英双语安装及全界面切换；支持常规、夜间、黑金、系统外观。

- 在本机导入、分类、分组和管理自己的视觉 Skill。
- 通过自己的 Codex 账号提交文字与参考图，自动接收生成结果，管理项目及连续修改版本。
- 提供备份恢复、手动更新入口、脱敏排障信息与精修后的自适应设置界面。
- 安装包不包含作者项目、私人图片、第三方 Skill 收藏或登录凭证。

**要求与限制**：需要兼容的 Codex CLI、自己的 ChatGPT 登录及实际可用的图片工具；生成消耗账号额度，并非离线。当前未签名，仅支持手动下载安装更新；Windows 可能提示未知发布者。暂无 macOS/Linux 包。第三方 Skill 兼容性需逐项验证。

朋友在另一台电脑安装测试：作者于 2026-10-19 反馈通过；此为用户报告，不是发布脚本采集的独立机器自动验收证据。

下载 `Skill-Canvas-0.62.0-Setup.exe`，不要把 Source code ZIP 当作安装包。建议先比较同版本 SHA256。更新前请备份、关闭应用，覆盖安装到原位置，不删除数据目录。

## English

First public Windows x64 preview with Chinese/English installation and interface, plus Light, Dark, Gold and System appearance.

- Import, classify, group and manage your own visual Skills locally.
- Submit prompts and reference images through your own Codex account, receive outputs automatically, and keep projects and revision versions.
- Backup/restore, manual release access, redacted diagnostics and refined responsive Settings.
- No author's projects, private images, installed third-party Skill collection or login credentials are included.

**Requirements and limitations**: compatible Codex CLI, your own ChatGPT login, and available image tools. Generation uses account allowance and is not offline. Unsigned, manual-update preview; Windows may warn about an unknown publisher. No macOS/Linux installer. Third-party Skill compatibility varies.

The author reported a friend's successful installation on another computer on 2026-10-19. This is user-reported acceptance, not independently collected automated evidence.

Download `Skill-Canvas-0.62.0-Setup.exe`, not the Source code ZIP. Compare its SHA256 if desired. Before an update, back up and close the app, then install over the existing location without deleting the data directory.
