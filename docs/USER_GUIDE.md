# Skill Canvas 使用指南

[English](USER_GUIDE.en.md) · [返回项目介绍](../README.md)

## 安装与准备

1. 从[官方 Releases](https://github.com/ablaze2432687090-byte/skill-canvas/releases)下载最新测试版的 `Setup.exe`。源码 ZIP 不是安装包。
2. 可用 PowerShell 检查文件：`Get-FileHash .\Skill-Canvas-0.62.0-Setup.exe -Algorithm SHA256`，与同版本 `.sha256` 文件比较。哈希校验不等于发布者签名。
3. 安装包未签名。遇到 Windows 提示时先核对来源，不要关闭系统安全保护；不确定就不要运行。
4. 选择安装语言与位置，完成后启动 Skill Canvas。无需另装 Node.js 或 pnpm。
5. 安装并登录你自己的 Codex CLI。到「设置 → 使用准备」检查程序、ChatGPT 登录及 Bridge 状态；找不到程序时可手动选择。
6. 「生成测试图并验证」会实际使用账号额度，只在你主动操作时执行。能否生图依赖你的账号权限、Codex 版本与可用工具，不保证所有账号一致。

## 添加与整理 Skill

1. 打开「Skill 管理 → 添加 Skill」，选择 GitHub、ZIP 或本地文件夹。
2. 文件应含有有效的 `SKILL.md`。检查名称、说明、来源、许可、输入要求与运行状态，确认后安装。
3. 只有兼容并可运行的 Skill 才能直接生成。需要其他服务、密钥或软件的 Skill 可能需要额外配置；工具不会替你自动执行未知安装脚本。
4. 可修改个人展示名称与简介、分类、标签、分组、封面和案例；这些展示设置不修改原始 Skill 指令。
5. 安装页的「生成封面与案例」是可选且消耗额度的操作。目前单图兼容 Skill 生成 1 张封面＋1 张案例；有必需图片或成组输出要求的 Skill 按其实际能力处理。

## 生成与继续修改

1. Skill 库 → 详情 → 使用此 Skill。
2. 提示词填写这次要做的内容；基础 Skill 指令由工具独立应用，无需全部复制到提示词里。
3. 按需上传参考图，设置风格、主体、构图或编辑对象等角色。输入要求以所选 Skill 为准。
4. 选择画面比例、目标尺寸及可用参数。预览跟随目标画布，但不会拉伸原图；请求尺寸不保证等于最终生成像素。
5. 点击「在 Codex 中生成」，等待真实执行结果。关闭应用可能中断任务，不要把关窗当成后台运行。
6. 结果页可查看图片、真实执行 Prompt、参数和历史版本，下载正式保存的原文件。
7. 在已有项目中继续修改会复用线程并创建新版本。「我的创作」可在重开后恢复项目。

## 日常管理

- 「我的创作」支持分组、搜索、多选、复制和删除。删除前看清确认内容，正式删除不可用“重新安装应用”恢复。
- 详情图片可打开浮窗；Ctrl＋滚轮缩放，拖动平移，点击浮窗外或按 Esc 关闭。
- 返回列表保留浏览位置；右下按钮可回到顶部或刷新当前页面。
- 设置内容直接显示，不需要展开。支持中文／英文、常规／夜间／黑金／系统主题及文字大小。
- Skill 的更新、锁定与回滚在 Skill 管理中操作。应用安装更新不会替你更新 Skill。

## 备份与数据

在「设置 → 数据备份与恢复」创建备份；自动备份需要选择备份位置并保存设置，且只在应用打开时检查执行。

默认数据位于 Windows「文档」下的 `Skill Canvas` 文件夹，实际位置以设置中「项目数据位置」为准。可迁移到你选择的位置。项目、参考图、原图、Skill 和设置与应用安装目录分离。

备份可能包含私人 Prompt、图片和 Skill，不要上传到公开 GitHub 仓库。跨电脑恢复后，需在新电脑重新登录 Codex并验证生图能力；备份不携带登录凭证。

## 手动更新

1. 先备份，并结束或取消当前生成任务。
2. 关闭 Skill Canvas。
3. 从官方 Releases 下载版本号更高的测试版 `Setup.exe`，查看更新说明并校验 SHA256。
4. 安装到原位置，不删除独立数据文件夹。
5. 重新打开，检查应用版本、已有项目、Skill 和设置。

当前没有自动下载和自动安装应用更新。不要依赖 GitHub 的“latest”跳转寻找预发布版本，请直接查看 Releases 列表。

## 常见问题

| 情况 | 处理 |
|---|---|
| 安装包显示“不能预览二进制” | 在 Windows 文件资源管理器中运行下载好的 `.exe`，不是在聊天附件预览里打开 |
| 找不到 Codex／未登录 | 到使用准备重新检测或选择程序，在 Codex 中完成自己的账号登录 |
| Skill 需要配置 | 查看运行问题和原作者要求；不要把“已导入”当成“已通过生图验证” |
| 无法生图或额度不足 | 查看真实错误与账号额度；不要反复提交同一个生成任务 |
| Bridge 异常 | 设置中重新检测或重启本地 Bridge，保留原项目后重试 |
| 图片缺失 | 确认数据位置和磁盘可用，优先从备份恢复，不清理正式项目目录 |
| 需要反馈问题 | 导出脱敏诊断后在 Issues 描述复现步骤；勿上传原始日志、私人图片、Prompt 或登录资料 |
